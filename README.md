# GER Detect Inspired WoodMart Child Theme

This repository contains a WordPress child theme for the WoodMart theme. It provides an original ecommerce landing page inspired by premium detector-store layouts, with sections for hero content, featured products, treasure/void devices, long-range systems, certifications, and footer navigation.

## Important image note

The referenced website's images and exact visual assets are not included. Upload images you own or have permission to use through the WordPress media library or WoodMart page builder, then replace the placeholder blocks in `page-gerdetect-home.php`.

## Installation

1. Install and activate the WoodMart parent theme.
2. Copy this folder into `wp-content/themes/gerdetect-inspired/`.
3. Activate **GER Detect Inspired WoodMart Child** in WordPress.
4. Create a page and select the **Detector Store Landing** template.
5. Replace placeholder content, contact details, prices, and product links with your store's real WooCommerce data.

## Files

- `style.css` declares the child theme metadata.
- `functions.php` loads WoodMart and child landing styles.
- `page-gerdetect-home.php` defines the landing page template.
- `assets/css/landing.css` contains the page styling.
